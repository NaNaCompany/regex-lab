Syntax and scope
Uses JavaScript RegExp syntax, which can differ from PCRE or Python. Without g only the first match is processed; y matches consecutively at the current position. Replacement $& means the whole match, $1 a capture, $<name> a named group, and $$ a dollar sign. Patterns run only in a separate Worker, terminated after 1 second. Above 500 matches only the first 500 are replaced and the remaining text is kept. Output is limited to 500,000 characters. Refresh clears inputs.
